Wumpus World – Artificial Intelligence Concepts

Core theoretical AI foundations illustrated by this simulation

1. Partially Observable Environment ▼
The agent cannot perceive the entire cave grid at once. At any time step, it only receives local sensory percepts (Stench, Breeze, Glitter, Bump, Scream) in its current room. It must overcome partial observability by maintaining internal state and an explicit knowledge base.
2. Knowledge-Based Agent ▼
A knowledge-based agent uses a formal Knowledge Base (KB) to represent facts about the world. Unlike reflex agents, it does not act solely on immediate percepts; it stores past percepts, infers unobserved hidden states, and acts based on logical truth.
3. Logical Inference & Propositional Logic ▼
The agent employs propositional deduction rules:
• \(\neg \text{Breeze}(x,y) \implies \forall (nx,ny) \in \text{Adj}(x,y): \neg \text{Pit}(nx,ny)\)
• \(\neg \text{Stench}(x,y) \implies \forall (nx,ny) \in \text{Adj}(x,y): \neg \text{Wumpus}(nx,ny)\)
• By intersecting stench candidate sets across rooms, the single Wumpus can be precisely triangulated without guessing.
4. Rational Agent & Decision Making ▼
A rational agent acts to maximize its expected performance measure given its percept sequence and built-in knowledge. It prioritizes guaranteed safe exploration over reckless guesses, strategically shoots its single arrow when a monster blocks the goal, and backtracks to safety if no safe path exists.
5. Search Algorithms (Breadth-First Search) ▼
To navigate between distant safe rooms or return home to (1,1) with the gold, the agent uses Breadth-First Search (BFS) restricted strictly to proven safe rooms. This guarantees the shortest safe path without risking pit falls or monster encounters.
6. State Space Formulation ▼
The agent's state space consists of its current coordinate \((r, c)\), facing orientation \(\in \{\text{North, East, South, West}\}\), gold inventory state, arrow inventory state, alive flag, and its accumulated Knowledge Base \(\text{KB}\).
7. Performance Measure (PEAS) ▼
• Performance Measure: +1000 for gold escape, -1000 for death (pit or wumpus), -1 per action/move, -10 for shooting arrow.
• Environment: 4×4 grid of rooms surrounded by walls.
• Actuators: MoveForward, TurnLeft, TurnRight, GrabGold, ShootArrow, Climb.
• Sensors: [Stench, Breeze, Glitter, Bump, Scream].
